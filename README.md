# POS Chrome Extension

This project is a React-based Chrome extension for Point-of-Sale (POS) functionality. It uses Webpack for bundling and MUI for UI components.

## Features

- QR code generation and display
- Network selection
- Responsive design

## Development

Install dependencies:

```bash
npm install
```

Run in development mode:

```bash
npm start
```

Build for production:

```bash
npm run build
```
